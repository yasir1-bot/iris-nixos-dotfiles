# Iris-Centered NixOS Dotfiles

Declarative NixOS + Flakes + Home Manager dotfiles for a **MangoWC** desktop with a **Noctalia-inspired Quickshell** shell. **Iris** is the single palette source for the shell and applications.

Layout: `system/` · `desktop/` · `apps/` · `shell/` · `scripts/` · `docs/`
